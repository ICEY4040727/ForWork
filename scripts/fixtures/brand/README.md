# Retired brand fixtures

English | [中文](README.zh.md)

These files preserve the upstream contours and atlas hash that `verify-brand-assets` rejects. They are inputs to the rejection spec, not shipped artwork; the gate scans only the brand roots listed in `specs/001-office-agent-framework/contracts/brand-artwork.contract.md`.

- `retired-whale.svg` — the DeepSeek whale silhouette fragment from the retired `FishLogo`.
- `retired-wordmark.svg` — a lettering fragment from the retired DeepSeek wordmark.
- `retired-favicon.svg` — the blue favicon contour.
- `retired-home-atlas.sha256` — SHA-256 of the removed `breach-atlas.webp`.
